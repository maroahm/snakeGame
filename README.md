## 📖 Overview
A modern, lightweight implementation of the classic arcade Snake Game. This project was developed to explore fundamental game development concepts, including the game loop, grid-based rendering, state management, and collision detection. 

The objective is simple: navigate the snake to eat the food, grow your tail, and survive as long as possible without hitting the walls or yourself!

## ✨ Features
* **Classic Gameplay:** Grid-based movement with precise controls.
* **Dynamic Scoring:** Real-time score tracking that updates as you eat.
* **Collision Detection:** Automatic Game Over when hitting the boundaries or the snake's own body.
* **Increasing Difficulty:** (Optional) The snake speeds up as the score increases.
* **Responsive State:** Simple restart mechanism upon Game Over.

## 🛠️ Tech Stack
* **Language:** JavaScript (ES6+)
* **Rendering:** HTML5 `<canvas>` API
* **Styling:** CSS3

## 🎮 How to Play
**Controls:**
* ⬆️ **Up Arrow** or **W**: Move Up
* ⬇️ **Down Arrow** or **S**: Move Down
* ⬅️ **Left Arrow** or **A**: Move Left
* ➡️ **Right Arrow** or **D**: Move Right

**Rules:**
1. Eat the red food block to grow and gain points.
2. Do not crash into the walls.
3. Do not crash into your own tail.
